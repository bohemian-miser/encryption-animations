How Toy RSA Mathematics Works:

1. Key Generation Setup:
• Choose prime numbers: p = 251 and q = 257.
• Calculate modulus: n = p × q = 64507 (Shared publicly. Caps message size).
• Calculate Carmichael totient: λ(n) = lcm(p-1, q-1) = lcm(250, 256) = 32000.
• Choose public exponent: e = 17 (coprime to 32000). Public Key: (e=17, n=64507).
• Calculate private exponent: d = e-1 mod λ(n) = 26353 (since 17 × 26353 ≡ 1 mod 32000). Private Key: (d=26353, n=64507).

2. Cryptographic Steps:
• Encryption: Ciphertext c = me mod n. E.g. for plaintext m = 43690: 4369017 mod 64507 = 47288.
• Decryption: Plaintext m = cd mod n. E.g. for ciphertext c = 47288: 4728826353 mod 64507 = 43690.

3. Binary Exponentiation (Repeated Squaring):
• Computing 4728826353 directly would produce a number with over 120,000 digits! To avoid integer overflow, the system writes the exponent as a sum of powers of 2 (e.g. 17 = 16 + 1). It squares the base modulo n at each step (e.g. m2 = (m1)2 mod n, m4 = (m2)2 mod n, etc.) and only multiplies the needed powers together, keeping numbers small.
