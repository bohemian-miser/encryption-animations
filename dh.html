How Diffie-Hellman Key Exchange Works:

1. Public Parameters Setup:
• Alice and Bob agree publicly on a prime modulus p = 997 and a generator base g = 2.

2. Private & Public Key Computation:
• Alice chooses a secret private key a (e.g. a = 15) and computes public value A:
    A = ga mod p = 215 mod 997 = 864.
• Bob chooses a secret private key b (e.g. b = 23) and computes public value B:
    B = gb mod p = 223 mod 997 = 303.

3. Public Exchange:
• Alice sends A (864) to Bob, and Bob sends B (303) to Alice over the insecure channel.

4. Calculating the Shared Secret:
• Alice computes the shared secret S using Bob's public value: S = Ba mod p = 30315 mod 997 = 387.
• Bob computes the shared secret S using Alice's public value: S = Ab mod p = 86423 mod 997 = 387.
• Both parties arrive at the identical secret S = 387 (hex `01 83`) without ever sending their private keys over the network!
